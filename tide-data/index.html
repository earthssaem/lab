📥 데이터 다운로드 방법
1. 바다누리 해양정보 서비스에 접속하여 상단 메뉴에서 [내려받기]로 이동합니다. (회원가입·로그인 창이 뜨면 진행)
2. 아래 메뉴에서 다음과 같이 순서대로 선택합니다.
• 자료구분: 조석 성과 선택
• 자료 종류: 1시간 조위 선택
• 자료 유형: 월별 선택
• 관측소 유형: 조위관측소 선택
• 관측소 선택: 분석할 관측소명 선택
• 연도: 태풍이 발생했던 연도 선택 3. [검색] 버튼 클릭 후, 검색 결과 표에서 분석할 월의 [다운로드] 버튼을 클릭해 파일을 받습니다.
